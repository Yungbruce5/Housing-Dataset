# Housing Dataset Analysis

This project explores a housing sales dataset and examines which property features are related to sale prices. It includes Jupyter notebooks, CSV data, visualizations, and a written exploratory data analysis report.

## Project contents

- `Housing dataset.ipynb` — main notebook for the housing data analysis.
- `Untitled.ipynb` — additional notebook.
- `train.csv` and `test.csv` — training and test datasets.
- `sample_submission.csv` — example submission file.
- `data_description.txt` — descriptions of the dataset fields.
- `01_saleprice_distribution.png` through `05_top_saleprice_correlations.png` — charts produced during the analysis.
- `House_Prices_EDA_Findings.docx` and `House_Prices_EDA.pdf` — written analysis findings.
- `house-prices-advanced-regression-techniques/` — a copy of the original competition data files.

## Open the analysis

Open `Housing dataset.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab. The notebook uses the CSV data in this project folder.

## Data

The project contains housing data files (`train.csv`, `test.csv`, and `sample_submission.csv`) along with `data_description.txt`, which explains the dataset columns.
